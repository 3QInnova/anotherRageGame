EXCEPTION: HUMAN / OBSERVER DESK

Five fresh players. No coaching.

Use people who have not played yet. Allow up to twenty minutes each: the first three Localhost servers, then Lab 9. Each link uses separate anonymous saves. Normal campaign progress stays separate.

Put the phones on the same Wi-Fi as this Mac. Scan one participant’s QR code per person. Results stay on that phone: use Export feedback at the end, share the JSON file to the Mac, then import it here. Keep this Mac awake while people play.

  1. Say: “Try to escape. You can stop whenever you want.” The game explains its controls.
  2. Watch quietly. Note laughter, hesitation, repeated mistakes, and whether they choose another attempt. Help only if the interface breaks; record the intervention.
  3. If they stop early, use Pause → End playtest. At the end ask what they would change, whether they understood their failures, and whether they would play again.
  4. Compare the five sessions. Treat repeated confusion as a tuning lead. This small test is qualitative feedback, not proof of retention.
