# Curated Play Store evidence

This is the explicit Git exception for screenshots selected as Play Store submission or release-review evidence. No evidence images have been selected or uploaded by creating this directory.

Copy only the final relevant image from an ignored `outputs/` run. For each image, record:

| File | Submission or review purpose | App version/build and source revision | Device, OS and capture date | What it demonstrates |
| --- | --- | --- | --- | --- |

Use the build's actual source revision; identify local modifications when the build differs from that revision. Keep raw runs, simulator recordings, logs, packages, alternate screenshots and ordinary QA captures in `outputs/`. The image exceptions here permit PNG, JPG, JPEG and WebP, including a `screenshots/` subdirectory. Avoid private device/account information in selected captures.

The exception is a repository policy, not a claim about which evidence Google requires. Confirm the relevant submission requirements when preparing a release. See [the project artifact policy](../../../ARTIFACT_POLICY.md).
